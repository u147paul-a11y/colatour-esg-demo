# 可樂旅遊永續網站 Demo

## 怎麼預覽
1. 解壓縮 ZIP。
2. 打開資料夾，雙擊 `index.html`，用 Chrome 開啟。
3. 網站圖片使用線上圖片，因此預覽時需要連上網路。

## 怎麼放到 GitHub Pages
1. 登入 GitHub，新增一個 Repository，例如 `sustainability-demo`。
2. 建議先選 Public（GitHub Free 的公開網站通常使用 Public repository）。注意：發布的網站會公開給任何人瀏覽，請勿放入內部資料或個資。
3. 在 Repository 裡選 `Add file` → `Upload files`。
4. 把 `index.html` 拖曳上傳到 repository 最上層，按 `Commit changes`。
5. 進入 `Settings` → `Pages`。
6. 在 `Build and deployment` 的 `Source` 選 `Deploy from a branch`；Branch 選 `main`，資料夾選 `/(root)`，按 `Save`。
7. 等待部署完成，回到 Pages 畫面按 `Visit site`。第一次可能需要幾分鐘。

## Demo 注意事項
- 網站的指標數字是示意資料，正式簡報前請換成公司核定數字。
- 圖片目前連結到 Unsplash 的線上圖片；若公司有核准的正式圖片，請替換圖片網址。
- 下拉選單是 Demo 錨點，會跳到首頁對應區塊，並非正式內頁。
- Logo 目前是文字版示意，正式版本請替換成公司核准的 Logo 圖檔。
